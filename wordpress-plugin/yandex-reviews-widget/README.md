# Yandex Reviews Widget - Легенда

WordPress плагин для отображения отзывов с Яндекс.Карт для стоматологической клиники "ЛЕГЕНДА"

## 🚀 Возможности

- ✅ Автоматическая загрузка отзывов с Яндекс.Карт
- ✅ Красивый слайдер с 3 отзывами на экране
- ✅ Адаптивный дизайн (мобильные, планшеты, десктоп)
- ✅ Настройка через виджеты WordPress
- ✅ Шорткод для вставки в любое место
- ✅ Простая установка через ZIP архив

## 📦 Установка

### Способ 1: Через админ-панель WordPress

1. Скачайте архив `yandex-reviews-widget.zip`
2. Откройте WordPress → Плагины → Добавить новый
3. Нажмите "Загрузить плагин"
4. Выберите ZIP файл и нажмите "Установить"
5. Активируйте плагин

### Способ 2: Через FTP

1. Распакуйте архив
2. Загрузите папку `yandex-reviews-widget` в `/wp-content/plugins/`
3. Активируйте плагин в WordPress

## 🎯 Использование

### 1. Через виджеты

1. Перейдите в **Внешний вид → Виджеты**
2. Найдите виджет **"Отзывы Яндекс.Карты"**
3. Перетащите его в нужную область (сайдбар, футер и т.д.)
4. Настройте заголовок и URL организации
5. Сохраните

### 2. Через шорткод

Вставьте в пост или страницу:

```
[yandex_reviews]
```

С параметрами:

```
[yandex_reviews title="Отзывы наших пациентов" org_url="https://yandex.ru/maps/org/legenda/88154393306/"]
```

### 3. В коде темы (PHP)

```php
<?php echo do_shortcode('[yandex_reviews]'); ?>
```

## ⚙️ Параметры шорткода

| Параметр | Описание | По умолчанию |
|----------|----------|--------------|
| `title` | Заголовок виджета | "Отзывы пациентов..." |
| `org_url` | URL организации на Яндекс.Картах | Клиника Легенда |

## 🎨 Дизайн

Виджет использует минималистичный дизайн в серых тонах (#5b5b5b, #050505), соответствующий стилю сайта клиники.

### Основные элементы:

- **Заголовок** с названием клиники
- **Рейтинг** со звездами и средней оценкой
- **3 карточки отзывов** с именем, датой, текстом
- **Навигация** — стрелки и точки для листания

## 📱 Адаптивность

- **Десктоп** — 3 колонки отзывов
- **Планшет** — 2-3 колонки (автоподстройка)
- **Мобильный** — 1 колонка
