Виджет отзывов с Яндекс.Карт для стоматологической клиники "ЛЕГЕНДА"

== Description ==

Плагин выводит отзывы с Яндекс.Карт в виде красивого виджета-слайдера.

**Основные возможности:**

* Автоматическая загрузка отзывов с Яндекс.Карт
* Слайдер с отображением 3 отзывов одновременно
* Адаптивный дизайн для всех устройств
* Настройка через виджеты WordPress
* Поддержка шорткода для вставки в любое место

**Использование:**

1. **Через виджеты:** 
   - Внешний вид → Виджеты
   - Перетащите "Отзывы Яндекс.Карты" в нужную область

2. **Через шорткод:**
   - Вставьте в пост/страницу: `[yandex_reviews]`
   - С параметрами: `[yandex_reviews title="Мои отзывы" org_url="https://yandex.ru/maps/org/..."]`

3. **В коде темы:**
   ```php
   <?php echo do_shortcode('[yandex_reviews]'); ?>
   ```

**Параметры шорткода:**

* `title` - заголовок виджета
* `org_url` - URL организации на Яндекс.Картах

== Installation ==

1. Загрузите папку плагина в `/wp-content/plugins/`
2. Активируйте плагин через меню "Плагины" в WordPress
3. Используйте виджет или шорткод для отображения отзывов

== Frequently Asked Questions ==

= Как изменить URL организации? =

Вы можете указать свой URL через параметр `org_url` в шорткоде или в настройках виджета.

= Можно ли изменить количество отзывов? =

По умолчанию отображается 3 отзыва. Для изменения нужно редактировать файл script.js.

= Отзывы не загружаются =

Проверьте правильность URL организации на Яндекс.Картах.
