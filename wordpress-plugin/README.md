# Yandex Reviews Widget - Легенда

WordPress плагин для отображения отзывов с Яндекс.Карт для стоматологической клиники "Легенда".

## Описание

Виджет отзывов с Яндекс.Карт с гибкими настройками дизайна и фильтрации. Плагин автоматически загружает и отображает реальные отзывы с вашей организации на Яндекс.Картах.

## Возможности

- ✅ Автоматическая загрузка отзывов с Яндекс.Карт
- ✅ 3 варианта макета (1, 2 или 3 колонки)
- ✅ Настройка цветов (основной, акцентный, текст)
- ✅ Фильтры по рейтингу
- ✅ Сортировка отзывов (по дате, рейтингу)
- ✅ Адаптивный дизайн
- ✅ Виджет и шорткод
- ✅ Резервные отзывы при недоступности Яндекс.Карт

## Установка

1. Скачайте папку `yandex-reviews-widget`
2. Загрузите её в `/wp-content/plugins/` на вашем WordPress сайте
3. Активируйте плагин через меню "Плагины" в WordPress

## Настройка

После активации плагина:

1. Перейдите в **Отзывы Яндекс** в меню администратора
2. Укажите URL вашей организации на Яндекс.Картах:
   - Формат: `https://yandex.ru/maps/org/legenda/88154393306/reviews`
3. Настройте макет (1, 2 или 3 колонки)
4. Выберите цвета интерфейса
5. Включите/отключите фильтры
6. Выберите сортировку по умолчанию

## Использование

### Шорткод

Вставьте шорткод в любой пост или страницу:

```
[yandex_reviews]
```

С параметрами:

```
[yandex_reviews layout="2-column" show_filters="true"]
```

### Виджет

1. Перейдите в **Внешний вид → Виджеты**
2. Найдите "Yandex Reviews Widget"
3. Перетащите в нужную область
4. Настройте параметры виджета

## Параметры шорткода

- `layout` - Макет: `1-column`, `2-column`, `3-column`
- `show_filters` - Показать фильтры: `true` или `false`
- `primary_color` - Основной цвет (hex)
- `accent_color` - Акцентный цвет (hex)
- `text_color` - Цвет текста (hex)

## Технические требования

- WordPress 5.0 или выше
- PHP 7.4 или выше
- Активное подключение к интернету
